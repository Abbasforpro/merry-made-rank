      Connect free live data

      The listing optimizer, title builder and fee calculator work everywhere with no setup. Live keyword numbers need a free Etsy developer key, and the page must run from a normal website (free GitHub Pages works) because this preview blocks outside connections.

      Get a free Etsy key
      1. Go to developer.etsy.com, sign in with your Etsy account, and choose Create a New App.
      2. Describe it honestly, for example "personal keyword research for my own shop". Pick the personal access option.
      3. Once approved, copy the Keystring and Shared Secret and paste them above as keystring:secret.
      4. The free tier allows about 10,000 requests a day. One keyword analysis uses 1 request, Load top shops uses up to 20.
      Set up the free connector (only if Test connection asks for it)
      1. Etsy blocks websites from calling it straight from the browser. A tiny free Cloudflare Worker passes the request along for you. The free plan allows 100,000 requests a day.
      2. Sign up free at dash.cloudflare.com. Open Workers & Pages, choose Create, then Create Worker. Name it merry-made-rank and click Deploy.
      3. Click Edit code, delete what's there, paste the contents of worker.js from github.com/Abbasforpro/merry-made-rank, and click Deploy.
      4. Optional but safer: in the worker's Settings, under Variables and Secrets, add a Secret named ETSY_KEY with your keystring:secret. Then leave the key box above empty.
      5. Copy the worker address, for example https://merry-made-rank.yourname.workers.dev, paste it in Connector address above, and tap Test connection.
      Where this tool lives
      1. Merry Made Rank is hosted free on GitHub Pages at abbasforpro.github.io/merry-made-rank.
      2. If Etsy asks for your app's website or allowed address, use https://abbasforpro.github.io.
      3. Your key is saved only in the browser you paste it into. It is never stored on GitHub, so paste it again on a new phone or computer.
